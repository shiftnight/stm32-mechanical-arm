# STM32 机械臂控制项目

基于 STM32F103C8 的裸机机械臂控制固件。工程使用 STM32F10x 标准外设库和 Keil MDK/uVision，包含串口控制、PS2 手柄输入、舵机平滑运动、W25Q64 动作组存储，以及一个平面连杆逆运动学实现。

## 功能概览

- USART1、USART3：115200 波特率，接收文本命令并输出调试信息。
- 6 路实体舵机输出：底座、肩、肘、腕、腕部角度和夹爪。
- TIM2 中断分时生成舵机脉冲，并按目标时间插值更新位置。
- PS2 手柄通过 GPIO 模拟串行时序读取按键。
- W25Q64 外部 SPI Flash 保存舵机偏差、上次位置、开机命令和动作组。
- SysTick 提供毫秒时基，按键、LED、PS2 和动作组任务在主循环中调度。

## 构建

1. 使用 Keil MDK/uVision 打开 `MDK-ARM/project01.uvprojx`。
2. 工程配置面向 STM32F103C8、Cortex-M3 和 ARM Compiler 5；根据本机 Keil 安装情况检查工具链及器件包。
3. 编译并使用兼容的 ST-Link/串口下载方式烧录到目标板。

仓库包含固件源码和 Keil 工程配置，不包含第三方上位机/烧录工具的可执行程序。此处未记录实际板卡接线、电源规格或舵机型号；上电前应按硬件实物核对。

## 主要引脚

| 功能 | 引脚 |
|---|---|
| 舵机 0–5 | PB3、PB8、PB9、PB6、PB7、PB4 |
| USART1 | PA9 (TX)、PA10 (RX) |
| USART3 | PB10 (TX)、PB11 (RX) |
| SPI2 / W25Q64 | PB12 (CS)、PB13 (SCK)、PB14 (MISO)、PB15 (MOSI) |
| PS2 手柄 | PA12–PA15 |
| 按键 | PA8、PA11 |
| LED | PB13，与 SPI2 SCK 共用 |

代码中的舵机状态数组有 8 个槽位，但只有编号 0–5 连接到实际 GPIO。编号从 0 开始。PB3/PB4 与调试功能复用；初始化时的 SWJ 重映射会影响调试器连接。

## 串口命令示例

```text
#001P2000T1000!   将索引 1 的舵机移动到 2000 μs，运动时间 1000 ms
#001PR+0500T1000! 从当前位置增加 500 μs，运动时间 1000 ms
#001PDST!         停止索引 1 的舵机
$DJR!             所有舵机回中
$DST!             停止所有舵机
$DGS:0!           执行动作组 0
```

串口帧以 `$`、`#`、`{` 或 `<` 作为起始符，根据模式以 `!` 或 `>` 结束。更多命令格式见 `Application/app_servo/app_servo.c` 和教学文档。

## 已知限制

- 两个 USART 共用一套接收缓冲区和状态变量，不能可靠地并行接收两条命令。
- 逆运动学命令解析格式与 `$` 起始帧存在不匹配，使用前需核对并修正 `parse_cmd()` 中的 `sscanf` 格式。
- 外部串口数据和动作组编号应增加完整格式及范围校验；当前部分解析路径没有先验证所有数组下标或 Flash 地址。
- 绿色模式的 PS2 映射包含 `$DCR` 底盘命令，但当前命令解析器没有对应处理分支。
- `app_key_run()` 中 KEY1 会擦除 W25Q64 第 0 扇区并写入测试数据，可能覆盖动作组 0。
